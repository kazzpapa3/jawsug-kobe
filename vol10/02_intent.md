## 2. 要件定義

### 2-1. intent.md の作成

システムの意図を伝える intent（＝意図）ファイルを作成します。

```bash
cat > features/oogiri-systems/intent.md << 'EOF'
# oogiri-system（大喜利システム）の意図

AWS 初学者から習熟しているユーザーまで、幅広い世代に向けた日本のお笑い文化に「大喜利」があります。
大喜利では、あるお題に対してユーモアとウィットに富んだ回答をし、回答の面白さや高度さなどの観点で競い合う言葉遊びとなっています。

AWS や AWS の各種サービスに関する出題に対し、回答を募るシステムを作り、AWS に関する知識の深さや着眼点を披露しあい、観衆のみならず出題者間で知識を高め合います。

完成した大喜利システムは、1〜2人のファシリテーター、5人程度の回答者、その他聴衆を集めた20人ほどの勉強会の場で実行されることを想定しています。

## ターゲットユーザー
AWS初学者から習熟しているユーザーまで、幅広い世代やリテラシーを持つAWS builderを対象とます

## 完成基準
- システムは AWS や AWS の各種サービスに関する出題をします
- 出題された問題に対し、回答者が回答を投稿することができます
- 投稿された回答を AI が判定し、回答やシチュエーションの面白さ、技術的な観点の正確性、独創性の観点から採点をします
EOF
```
